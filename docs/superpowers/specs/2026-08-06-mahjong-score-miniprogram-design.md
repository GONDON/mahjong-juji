# 川麻比分小程序 MVP 设计

**日期：** 2026-08-06  
**状态：** 已确认  
**产品名（暂定）：** 麻将局记 / TCMSP  
**形态：** 微信小程序  

## 1. 目标与非目标

### 目标（MVP）

- 固定熟人局（4–8 人常玩）能**当场快速记分**，打完一场夜局有完整流水。
- 内置**川麻血战**算分（基本番、附加番、杠分、庄家倍率），记分员不手填分数。
- **自动跟踪庄家与连庄**，避免桌上忘庄。
- 年底可评：**麻将之神**（累计 / 场均）与 **麻将最拉王**（累计 / 场均）。
- 架构预留「以后开放给陌生人局」，但不在 MVP 实现匹配/社交。

### 非目标（MVP 不做）

- 陌生人匹配、俱乐部、段位、语音。
- 趣味称号墙、分享海报（底层统计字段可先落库）。
- 多记分员同时写、复杂权限；记分员转让。
- 欠账、中途买牌/补牌。
- 按「把」之后再升级的数据结构：本版已按把记录，无需二次迁移。

## 2. 用户与角色

| 角色 | 权限 |
|------|------|
| 开房人 = 记分员 | 唯一可录分、撤销、结算、结束夜局 |
| 其余玩家 | 进房围观（只读）；可用临时昵称占座，以后绑微信 |

成功标准：记分员在一胡发生后，**约 10 秒内**完成「谁胡 / 自摸或点炮 / 番型 / 确认」，桌上其他人能看到牌数变化。

## 3. 领域模型（信息架构）

```
牌友圈 Circle（MVP 默认一个熟人圈；以后可公开）
 └── 夜局 Session
      ├── 设置：四人、牌面值、可选番开关
      └── 轮次 Cycle（开局选首庄 → 各发 20 牌 → 有人破产或手动结清 → 兑钱 → 可再开一轮并重新选庄）
           └── 局 Hand（一副血战）
                ├── 开局庄家 + 连庄数
                ├── 胡事件 HuEvent（0～多人）
                └── 流局（无人胡）
```

### 页面（MVP）

1. **首页** — 继续未结束夜局 / 开新房 / 本年榜入口  
2. **战场页** — 记分主场（四方桌）  
3. **夜局详情** — 各轮输赢、流水、纠错  
4. **年度榜** — 之神 / 最拉王（累计 + 场均）

## 4. 玩法与流程规则

### 4.1 夜局与轮次

1. 开房人设：**牌面值**（如 1/2/5 元每牌）、四人、可选番开关。
2. **每一轮开始**（含夜局第一轮，以及有人输光 20 牌结算后重开的下一轮）：
   - 记分员在开局界面**点选本轮首庄**（连庄数归零）。可附「掷骰子」辅助随机，但**以记分员最终点选/确认为准**。
   - 确认后每人发 **20 牌**，进入战场。
3. 轮内打多局血战，直到**有人牌数为 0**（或记分员点「本轮结清」）。
4. 结算：`兑现金额 = (当前牌数 - 20) × 牌面值`。
5. 若继续打：进入下一轮，**再次开局选庄**（不继承上一轮的庄/连庄）。
6. 不想打了 → 结束夜局；已结算轮次保留进年度统计。

**开局选庄（MVP）：** 四个座位大按钮，点谁谁当本轮第一局庄；可选骰子动画给出建议人选，记分员仍可改选后确认。

### 4.2 单局（血战）

- 一局内可多人依次胡；已胡者离桌（不可再胡），未胡者继续。
- 允许：**无人胡（流局）**、**仅一人胡其余流局**、多人胡。
- 自摸付款人 = 所有「未胡且仍有牌」的人；点炮 = 仅点炮者付。

### 4.3 庄家

| 情况 | 行为 |
|------|------|
| **每轮第一局** | 记分员开局**手动选择**首庄（可骰子辅助）；连庄数 = 0 |
| 轮内后续局 | 按上一局首胡者自动推演，无需再选手动选庄 |
| 开局锁定 | 本局开始时冻结「本局庄家」与「本局连庄数」；**算分只用冻结值**，本局内不改 |
| 某局产生首胡 | 记录首胡者，供**下一局**用。若首胡者 == 本局庄家 → 下局连庄数 = 本局连庄数 + 1且庄不变；否则下局庄 = 首胡者、连庄数 = 0 |
| 同局后续胡 | 不改变「下一局庄」的判定（只认首胡者）；若后续胡的人恰是本局庄家，**仍享受本局庄倍**（因整局按开局庄算） |
| 流局 | 下一局庄与连庄数**都不变** |
| 破产后新轮 | 结算后重开：再次进入「选首庄」界面，连庄清零 |
| 开局展示 | 每局开始即显示庄家与当前倍率 |

**庄家赢倍率（胡家 == 本局冻结庄家时乘；否则 ×1）：**

```
庄倍 = 2 + 本局冻结连庄数
# 首庄(连0) ×2，连1 ×3，连2 ×4，连3 ×5 …
```

「下庄」只影响下一局谁当庄，不追溯取消本局已按庄倍结算的胡。

## 5. 战场交互

### 5.1 布局：四方桌

- 顶栏：庄、连庄数、倍率、第几轮/第几局。
- 四人座位：昵称、牌数、已胡标记；庄家描边高亮。
- 点座位 → 录胡；已胡座位不可点。
- 底栏：`流局` / `撤销上一胡`。

### 5.2 录胡：常用番一键 + 附加开关

1. 自摸 / 点炮（点炮须选点炮者）。
2. **基本番**互斥大按钮（见番表）。
3. **附加番**可多选；根/杠上花等；「更多」放可选番。
4. 录入**明杠数、暗杠数**（用于杠分，见下）。
5. 实时预览应付明细 → 确认入账。

## 6. 算分引擎

单位：一律先记 **牌**；钱只在轮结时兑。

### 6.1 番积（不含杠分）

```
基础番积 = 基本番倍数 × ∏(附加番倍数)
# 根：每个 ×2；规则表中的「杠×2」不采用（杠改固定加牌）
单人番分应付 = 基础番积 × 庄倍
```

### 6.2 杠分（与番分相加，不是乘进番积）

- **未胡者的杠不计分。**
- 明杠：每个 **+1 牌**；暗杠：每个 **+2 牌**。
- 自摸：每个未胡者付 `单人番分应付 + 杠分合计`。
- 点炮：点炮者付 `单人番分应付 + 杠分合计`。

### 6.3 内置番表

**基本番（互斥）**

| 番型 | 倍 |
|------|-----|
| 平胡 | ×1 |
| 对对胡 | ×2 |
| 清一色 | ×4 |
| 七对 | ×4 |
| 金钩钩 | ×4 |
| 清对 | ×8 |
| 清七对 | ×16 |
| 清金钩钩 | ×16 |

**附加番**

| 番型 | 倍 |
|------|-----|
| 杠上花 | ×2 |
| 杠上炮 | ×2 |
| 抢杠胡 | ×2 |
| 海底捞月 | ×2 |
| 根 | 每个 ×2 |

**可选番（开房开关，默认建议全关或按桌约定）**

| 番型 | 倍 / 说明 |
|------|-----------|
| 门清 | ×2 |
| 中张 | ×2 |
| 带幺九 | ×4 |
| 将对 | ×4（不与中张叠；不适用于七对类） |
| 天胡 | 封顶 ×8 |
| 地胡 | 封顶 ×4 |

### 6.4 破产截断

某人应付超过剩余牌：先付到 0，**立即触发本轮结算**；展示截断说明。MVP 不记欠账。

## 7. 数据模型

| 实体 | 关键字段 |
|------|----------|
| Player | `playerId`，微信 openId（可空），昵称 |
| Circle | 名称；成员列表 |
| Session | circleId，面值，可选番配置，记分员，状态，四人座位 |
| Cycle | sessionId，起始牌 20，结束原因，结算金额快照 |
| Hand | cycleId，庄家，连庄数，流局标记，首胡者 |
| HuEvent | handId，胡家，自摸/点炮，点炮者，基本番，附加番列表，明杠数，暗杠数，庄倍，算分快照 |
| Transfer | 付款人，收款人，牌数，原因（番/杠） |

年度统计从已结算 Cycle 的人民币结果聚合；HuEvent 保留供趣味称号与回放。

## 8. 年度榜

- **麻将之神**：累计结算额最高 **与** 场均结算额最高（并排展示）。
- **麻将最拉王**：累计最低 **与** 场均最低（并排）。
- **口径**：按**人民币结算额**累计（避免不同面值桌不可比）。一场夜局 = 场均分母的 1 场。
- **场均门槛**：默认全年至少参与 **3** 场夜局才进场均榜（可配置）。
- 趣味称号：MVP 只积累事件统计，UI 下一版。

## 9. 纠错与容错

- 弹层未确认可取消；点炮未选人不可确认。
- 撤销上一胡（本局内）。
- 误点流局可在未开下一局前改回（若已开下局则不可轻易回滚）。
- 轮次结算确认后锁定；仅保留「整轮作废」（慎用，需二次确认）。
- 断网：单记分员写入；本地待同步队列（实现阶段细化）。
- **MVP 不做记分员转让**；开房人丢失则结束夜局，已结算轮次保留。

## 10. 技术方向

- 微信小程序 + 云开发（云数据库 + 云函数）。
- 房间码进房；写权限校验记分员。
- **算分纯函数**（输入：桌面状态 + 胡事件 → 输出：Transfer[]），便于单测。
- Circle / Player 稳定 ID，为公开局预留；MVP 仅熟人进房。

## 11. 测试要点（算分）

1. 非庄平胡点炮 → 点炮者付 1。  
2. 庄家首庄自摸对对胡，3 家未胡 → 每家付 4，胡家 +12。  
3. 连庄使倍率 ×4，清一色自摸 + 1 明杠 → 每家付 `4×4+1=17`。  
4. 点炮胡 + 1 暗杠 → 点炮者付番分 +2。  
5. 未胡者有杠 → 不影响任何人分。  
6. 流局 → 庄与连庄不变。  
7. 非庄首胡 → 下局庄切换、连庄清零。  
8. 付到 0 → 触发轮结，四家 `(牌-20)×面值` 展示。

## 12. 决策摘要

- 产品路线：**一桌战场**记分优先（非战后补记、非一上来做开放平台）。
- 布局：**四方桌**；选番：**常用一键 + 附加开关**。
- 杠：**胡了才算**；明杠 +1 / 暗杠 +2；按自摸/点炮对象加在番分上。
- 年度榜：人民币 + 累计/场均双列 + 场均门槛。
