# 大厅导航壳

**日期：** 2026-08-25
**状态：** 已确认
**范围：** 首页自定义顶栏与假 tab 底栏。开局 / 进房 / 占座 / 录胡 / 算分逻辑不动。
**形态：** 微信小程序（现有麻将局记）

## 1. 目标与非目标

### 目标

- 首页改回微信原生导航栏，标题「麻将局记」。
- 删掉首页假 tab 底栏（大厅 / 战场 / 流水 / 榜）。
- 角色卡和年度榜改由首页内容里的身份条进入，不再伪装成 App 壳。
- 战场、流水只从「最近牌局」（以及战场页已有的「牌局详情」）进入。

### 非目标

- 不引入微信原生 `tabBar`。
- 不改开局、进房、选庄、录胡、结清、角色卡校验、云函数。
- 不改选庄 / 战场 / 牌局详情 / 角色卡 / 年度榜页的内部布局。
- 不在其他页面复制身份条。
- 不改微信右上角胶囊（系统控件，不可删）。

## 2. 决策

产品是任务流，不是四个并列主页：大厅开局/进房 → 选庄 → 战场录胡 → 牌局详情。年度榜是低频出口。

假 tab 把全局目的地（大厅、榜）和某局子页（战场、流水）混在同一条栏里；「再入局」已经覆盖后两者。自定义顶栏又和微信胶囊叠成两层壳，左边牌面图标没有动作。

因此采用方案 B：两条产品自绘壳都去掉，只留微信原生顶栏；头像和年度榜落进页面内容。

## 3. 首页壳

### 3.1 系统导航

`pages/index/index.json` 去掉 `navigationStyle: custom`，与其它页一致：Paper 底、黑字。标题继承 `app.json` 的「麻将局记」，`index.json` 不重复写 `navigationBarTitleText`。

页面根节点不再为状态栏加 `padding-top`。删除首页的 `statusBarHeight`、`safeBottom` 和 `windowMetrics`：它们只服务自定义顶栏和 dock，其它页不依赖。

### 3.2 身份条

系统导航正下方、`快速开局` 正上方，一行内容，不是第二条工具栏：

- 不要底边框，不要和微信顶栏拼成双层导航。
- 左：方框头像（现有 `.face-frame`）。已设角色卡显示本人脸；未设显示默认脸 `avatar_00`。点 → `/pages/profile/profile`。
- 右：「年度榜」墨色字，不是胶囊主按钮，也不配第二套图标底栏。点 → `/pages/rank/rank`。文案固定「年度榜」，不带年份（榜页自己有「{{year}} 年度榜」）。

未设卡仍可点头像；引导设卡的逻辑保持现有角色卡页，不在首页拦截。

### 3.3 删除的 UI

- 自定义顶栏：牌面图标、居中「麻将局记」、顶栏内头像。
- 底栏 dock：大厅 / 战场 / 流水 / 榜 四个 tab，以及 `.dock` / `.tab` 样式和 dock 的底部安全区 padding。

## 4. 进出路径

全部用 `wx.navigateTo`。系统返回键回到上一页。不做 `switchTab`。

| 从哪 | 动作 | 到哪 |
|---|---|---|
| 首页身份条 | 点头像 | 角色卡 |
| 首页身份条 | 点「年度榜」 | 年度榜 |
| 快速开局 | 开牌局 | 现有开局路径（不改） |
| 加入牌局 | 四位房间码 | 现有进房路径（不改） |
| 最近牌局 | 进行中 / 选庄中 | 现有 `sessionRoute`：战场或选庄 |
| 最近牌局 | 已结束 | 牌局详情 |
| 战场底栏 | 牌局详情 | 当前局详情（已有，保留） |
| 选庄 | 未设卡去占座 | 角色卡（已有 `sessionId` 带回，保留） |

没有进行中的局时，首页不提供「去战场 / 去流水」捷径，也不 toast「先开一局或加入房间」或「还没有流水」。人停在大厅。

## 5. 代码删除

从首页实现和测试中删除：

- `onBattleTab` / `onHistoryTab` 以及 wxml 绑定。
- `battleTabTarget` / `historyTabTarget` / `TabTarget`：删 tab 后无调用方，一并删除。
- `tests/indexState.test.ts` 里的 `lobby tab targets` 用例。

`onRankTap` / `onProfileTap` 保留，改绑到身份条。`sessionRoute` 与「再入局」保留。

## 6. 其它页面

| 页 | 处理 |
|---|---|
| 选庄、战场、牌局详情、角色卡、年度榜、开新局 | 继续微信原生顶栏；内部布局不动 |
| 战场底栏 | 仍是操作栏（流局 / 本轮结清 / 撤销上一胡 / 牌局详情），不是导航 tab |
| 年度榜 | 页内「{{year}} 年度榜」标题保留 |

不在这些页加身份条或大厅 dock。

## 7. 文档

实现时同步：

- `DESIGN.md` Navigation：写明首页用微信原生顶栏；页内身份条是内容入口，不是 App 壳；禁止首页假 tabBar。
- `PRODUCT.md`「一职一面」补一句：角色卡与年度榜从大厅身份条进，战场与流水从最近牌局进。

## 8. 验收

- 首页可见微信原生标题「麻将局记」和右上胶囊；没有自定义顶栏，没有底栏四 tab。
- 点头像进角色卡，系统返回回到首页。
- 点「年度榜」进榜页，系统返回回到首页。
- 有进行中的最近牌局时，「再入局」仍进战场或选庄。
- 已结束行仍进牌局详情。
- 空最近列表仍是现有空状态，不因删 tab 而多出 toast。
- `indexState` 相关测试在删掉 tab 用例后仍通过。
