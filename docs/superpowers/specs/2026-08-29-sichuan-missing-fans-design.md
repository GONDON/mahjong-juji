# 川麻缺失番型补全

**日期：** 2026-08-29  
**状态：** 已确认  
**口径：** 成都血战老表（1 番 = ×1，每多 1 番翻倍）

## 目标

录胡能点到龙七对、清龙七对、将对、带幺九、中张、天胡、地胡；番积与老表一致。杠分、庄倍、自摸/点炮对象不变。

## 基本番（互斥）

| 番型 | 倍 | 说明 |
|------|-----|------|
| 平胡 | ×1 | 已有 |
| 对对胡 | ×2 | 已有 |
| 清一色 / 七对 / 金钩钩 | ×4 | 已有 |
| 清对 | ×8 | 已有 |
| 龙七对 | ×16 | 新增；减 1 根 |
| 清七对 / 清金钩钩 | ×16 | 已有 |
| 清龙七对 | ×32 | 新增；减 1 根 |

## 附加番

| 番型 | 倍 | 规则 |
|------|-----|------|
| 杠上花 / 杠上炮 / 抢杠 / 海底 / 门清 | ×2 | 已有；门清保持可点 |
| 中张 | ×2 | 界面补上；不与将对、带幺九同乘 |
| 带幺九 | ×4 | 界面补上。清一色+带幺九 = 清幺九 ×16 |
| 将对 | ×4 | 界面补上。对对+将对 = ×8；清对+将对 = ×32。七对类不计 |
| 天胡 | ×8 | 界面补上；仍按原封顶倍数 |
| 地胡 | ×4 | 界面补上；仍按原封顶倍数 |
| 根 | 每个 ×2 | 龙七对 / 清龙七对先减 1 根再乘 |

## 减根

`有效根 = max(0, 根数 - (龙七对或清龙七对 ? 1 : 0))`

- 龙七对 + 根 0 或 1 → ×16
- 龙七对 + 根 2（双龙）→ ×32

## 非目标

不改刮风下雨当场结算、查花猪、查大叫、一炮多响、呼叫转移。
